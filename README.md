# LinkPrice Design Portfolio

광고주 안내용 정적 웹 포트폴리오입니다. GitHub Pages에 바로 업로드할 수 있습니다.

## GitHub Pages 배포
1. GitHub에서 새 Public Repository를 생성합니다. (예: `linkprice-design-portfolio`)
2. 이 폴더 안의 `index.html`, `styles.css`, `script.js`, `assets` 폴더를 저장소 최상단에 업로드합니다.
3. 저장소 `Settings` > `Pages` 이동
4. `Build and deployment` > `Deploy from a branch`
5. Branch를 `main`, Folder를 `/(root)`로 선택 후 Save
6. 잠시 후 `https://계정명.github.io/linkprice-design-portfolio/` 형태로 접속할 수 있습니다.
